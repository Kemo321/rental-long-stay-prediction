## Project Overview
This project aims to support customer service consultants at a rental platform ("Nocarz") by predicting whether a browsing user is likely to book a long-term stay (**7+ days**). 

Instead of just providing a binary prediction, the core business value of this system is **explainability**. Using SHAP (SHapley Additive exPlanations), the model highlights the Top 3 key criteria (e.g., lead time, price, specific amenities) driving the user's decision, allowing consultants to proactively offer highly personalized recommendations.

## Machine Learning Task
* **Type:** Binary Classification & Feature Importance Analysis.
* **Target Variable:** `is_long_stay` (1 if stay length >= 7 days, 0 otherwise).
* **Models:** Baseline (Dummy Classifier) vs. Advanced (XGBoost).
* **Key Metrics:** ROC AUC (Baseline: ~0.50, XGBoost: ~0.96), Average Precision, and successful SHAP ranking generation.
* **A/B Testing:** The microservice implements a transparent A/B test (Baseline vs. XGBoost) with payload logging for continuous production evaluation.

## Tech Stack
* **Data Analysis & ML:** `pandas`, `scikit-learn`, `xgboost`, `shap`, `matplotlib`, `seaborn`
* **Deployment:** `FastAPI`, `uvicorn`, `Docker`, `Docker Compose`

## How to Run the Microservice
The prediction service is fully containerized. To start it, simply run:
```bash
docker-compose up --build -d
```
The API will be available at `http://localhost:8080`.

## How to Test the API (A/B Test & SHAP Explainability)
The service randomly assigns requests to either Group A (Baseline) or Group B (XGBoost). If you are assigned to Group B, the response will be enriched with a `top_deciding_factors` list generated by the SHAP explainer, directly answering the business requirements of Task 7.

```bash
curl -X 'POST' \
  'http://localhost:8080/predict' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "accommodates": 2,
  "bathrooms": 1,
  "bedrooms": 1,
  "beds": 1,
```

## Evaluating the A/B Test
To evaluate the performance of the deployed models:
1. Ensure the Docker container is running.
2. Execute all cells in `notebooks/generate_traffic.ipynb` to simulate 500 requests and populate the logs.
3. Open and run `notebooks/ab_test_evaluation.ipynb` to generate statistical comparisons and distribution charts comparing Group A and Group B.
